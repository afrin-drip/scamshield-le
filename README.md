## Overview

ScamShield LE is an Android app that protects users from phone scams where callers impersonate law enforcement. It monitors suspicious calls in real time and fires an immediate full-screen alert if scam patterns are detected.

> **Core Rule:** Real law enforcement does NOT demand immediate payment over the phone to avoid arrest. If that happens — hang up.
